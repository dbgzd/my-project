\chapter{相关理论与知识研究}
\label{ch:survey}

本章系统性回顾本研究涉及的关键技术，包括舆情数据采集与预处理、主题模型及其评价指标、稀疏注意力机制、预训练语言模型在情感分析中的应用、以及大模型轻量化微调方法与工程实现要点。文献回顾侧重于方法论的原理、适用条件与局限，并在必要处指出本研究所采用技术的理论依据与工程取舍。

\section{评价数据采集相关技术}
\label{sec:data_collection}

评价数据采集相关技术是指围绕电商平台、社交媒体或其他用户生成内容平台，对商品评价、评论文本、评分、时间戳、用户行为等原始信息进行自动化获取、结构化整理与持续更新的一类方法与工具。其核心目标是在尽量不破坏原始语义和上下文的前提下，稳定、合规地获取高质量数据，为后续的数据清洗、主题建模、情感分析与舆情监测提供基础。按照实现方式不同，这类技术通常包括接口抓取、网页爬虫、浏览器自动化、消息队列解耦、增量更新与异常重试等环节，并需要综合考虑反爬机制、数据一致性、采集效率与隐私合规等问题。

本文采用基于爬虫的评价数据采集方案，结合 Scrapy 与 Playwright 完成页面抓取与动态内容解析，并通过任务调度与队列化设计提升采集的稳定性与可扩展性。具体而言，采集任务由调度系统统一下发，抓取器负责登录、翻页与页面渲染处理，采集结果以 JSON Lines 形式落盘，同时保留抓取时间、请求参数与任务标识，便于后续审计、去重与增量更新。针对平台可能存在的反爬策略，本文进一步采用代理池、动态请求头、请求间隔控制和失败重试等手段，以降低封禁风险并保证评价数据的持续获取。

\section{评价数据分析相关技术}
\label{sec:topic_models}

本节所涉及的技术点在电商评论舆情分析流程中并非彼此独立，而是形成了从文本清洗、特征表示、主题抽取、效果评价到情感识别与联合推断的协同链路，共同支撑后续的模型设计与实验实现。

\subsection{中文文本清洗与分词技术}
中文评论数据在进入分析流程前通常需要经过文本清洗与分词处理，以去除 HTML 标签、表情符号、无效字符、广告文本及重复记录，并将连续文本切分为可计算的词项序列。对于电商评论这类短文本场景，规范化处理直接影响后续主题建模与情感分析的稳定性，因此通常还需结合停用词过滤、同义词归一和词形规范化等步骤，以提高语料的一致性与可用性。

\subsection{TF-IDF 文本表示技术}
TF-IDF 是电商评价分析中最常用的稀疏文本表示方法之一，它通过词频与逆文档频率的联合加权衡量词项的重要性，从而突出对单篇评论更具区分能力的关键词。相较于简单词袋模型，TF-IDF 能够在一定程度上抑制高频功能词的干扰，适合作为主题建模、分类任务和关键词抽取的基础特征表示。

\subsection{Sparse-HDP 主题建模技术}
Sparse-HDP 主题建模技术是在层次狄利克雷过程（HDP）框架上引入稀疏注意力机制，以增强词项到主题的选择性分配能力。该方法既保留了非参数贝叶斯模型自动推断主题数的优势，又通过稀疏化约束提升主题的集中性与可解释性，适合用于电商评论中多主题共存、噪声较多的分析场景。

\subsection{主题一致性与困惑度评价技术}
主题模型的效果通常通过主题一致性（Coherence）与困惑度（Perplexity）进行综合评价。前者从主题词之间的语义关联程度出发衡量主题的可解释性，后者从概率生成角度评价模型对文本分布的拟合程度。二者结合能够较为全面地反映主题模型在语义稳定性与统计拟合能力方面的表现。

\subsection{QLoRA 轻量化情感分析技术}
QLoRA 是面向大语言模型的轻量化微调方法，它在低比特量化模型的基础上引入低秩适配参数，仅需训练少量新增参数即可完成下游任务适配。对于电商评论情感分析而言，该方法能够在显著降低显存占用和训练成本的同时，较好保留预训练模型的语义理解能力，适用于资源受限条件下的模型部署与迭代。

\subsection{主题-情感联合推断技术}
主题-情感联合推断技术旨在在同一分析流程中同时输出文本的主题信息与情感极性，从而避免传统分步分析中主题与情感结果割裂的问题。该技术通常通过共享表示或联合决策机制实现，可以更细致地刻画“关于什么话题、表达了什么态度”的复合语义结构，为后续的舆情研判与报告生成提供统一结果。

\section{稀疏注意力机制与长序列表示}
\label{sec:sparse_attention}

Transformer 自注意力的二次复杂度在处理长序列时成为瓶颈。稀疏注意力通过结构化或可学习的稀疏模式降低计算与内存开销，同时尽量保留关键信息。常见方法包括局部窗口注意力、全局 token 机制、块状稀疏与可学习稀疏化（例如 Sparse Transformer、Longformer、BigBird 等），每种方法在信息保留能力与实现复杂度上存在权衡。

在本研究中，稀疏注意力的价值体现在两方面：一方面作为文本表示层，生成适合主题建模的段落/句子级向量以保留长程上下文；另一方面可与主题模型结合，通过注意力权重引导主题分配，以提高主题的稀疏性与可解释性。

\section{预训练语言模型在情感分析中的应用}
\label{sec:pretrained_models}

基于 Transformer 的预训练模型（如 BERT 及其变体）已成为情感分析的主流方法。其优势在于通过大规模语料学习到的上下文感知表征能够有效处理否定、修饰以及隐含情感表达。情感分类通常通过在任务数据上进行监督微调实现，评估指标以 Precision、Recall、F1 与 AUC 等为主。

细粒度情感任务（包括方面级情感分析、情感强度评分与多标签情感判定）通常需要在模型架构或数据标注上做相应设计，例如采用联合模型同时预测方面与极性，或引入多任务学习以共享表示并提高泛化能力。

针对资源受限或大模型部署场景，轻量化微调方法（如 LoRA、QLoRA）通过仅学习低秩适配参数或在量化模型上微调少量参数，实现显存与计算开销的大幅降低，从而在工程上具有显著价值。

\section{大模型轻量化微调与工程实践}
\label{sec:qlora}

QLoRA 将量化技术与低秩适配结合，允许在量化后的模型上以极小的额外参数完成微调。工程上需注意量化精度对下游任务性能的影响、LoRA 的秩选择对模型容量与可训练性的权衡，以及训练过程中的稳定性措施（学习率调度、梯度裁剪等）。

部署方面，建议结合混合精度、模型并行与批量推理优化推理吞吐；并通过持续监控（包括输入分布漂移检测与在线评估）维护模型长期性能。

\section{系统实现与技术栈评述}
\label{sec:tech_stack}

从工程实现角度，推荐的组件包括：数据采集与预处理管线（Scrapy/Playwright + ETL 作业）、存储层（关系型数据库 + Elasticsearch/文档库）、模型训练与服务化框架（PyTorch + Hugging Face + FastAPI/TorchServe）、以及可视化与监控平台（ECharts/Prometheus + Grafana）。实现要点包括模块化设计、可复现的数据版本控制以及自动化的模型验证与部署流水线。
